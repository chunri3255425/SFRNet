## 清单列义

`category, new_name, old_dir, old_name, series, capture_time, old_number, width, height, bytes, md5`

- `series`：`capture` = 手机直出（有真实拍摄时间）；`legacy_numbered` = 原编号系列（**无拍摄时间**）。
- `capture_time` 只来自文件名。`mtime` 全部是 2026-11-08 14:27–14:30，即**拷入本机的时间**，不能当拍摄顺序用，故未入列。

## 批次完整性（重要，别当完整批）

`clean` 原编号段是 **0001–0300**，磁盘只有 193 张 ⇒ **缺 107**，且缺失**散布**在每一段，不是尾部成段截断：

| 编号段 | 现存 | 缺 |
|---|---|---|
| 001–050 | 32 | 18 |
| 051–100 | 39 | 11 |
| 101–150 | 35 | 15 |
| 151–200 | 29 | 21 |
| 201–250 | 24 | 26 |
| 251–300 | 34 | 16 |

拷贝中断会表现为尾部成段缺失，这里不是那种形态 ⇒ 更像有选择地保留/删除。
**若删除标准与"看起来有没有纹"有关，负样本分布会被系统性拉向容易判对，误报率结论偏乐观。** 此点未澄清前，本批数据只能用于探索，不足以对外宣称误报率。

## 三个不可混池算指标的事实

142 种分辨率，且尺寸与标签近乎共线：

| 档 | `moire` | `clean` | 说明 |
|---|---|---|---|
| 宽 4096 / 3072（手机 4K 直出） | 291 | 0 | 全部是 `moire_0001..0291` |
| 宽 1280（窗口截图，高 285–20835） | 10 | 193 | 含一张 `clean_0187` 1280×20835 滚动长截图 |

- 只看"宽 ≥3000"这条**不看摩尔纹**的土规则：精度 100.0%，对正样本召回 96.7%。
  ⇒ 任何在这 494 张上混池算出的准确率，都可能只是分辨率在起作用，不是模型在起作用。
- 按 `tile_size 512 / stride 256` 算，每张图的滑窗块数从 0 跨到 320（`moire` 291 张恒为 165 块，`clean` 多为 4 或 8 块）。
  `coverage = mask.mean()` 的分母随块数变一个数量级 ⇒ **同一个覆盖率阈值在不同尺寸图上含义不同**，不能跨档共用。
  对照：`2275×1279 → 32 块`（与板端产品路径那次数值一致）、`4096×3072 → 165 块`。

## 顺带查出的产品缺陷（`[实测]`，未修）

`SlidingWindowEngine.plan()` 在**任一边 ≤512 而另一边 >512** 时抛 `IndexError`：小图兜底分支要求两边都 ≤512
（`app/logic_layer/sliding_window.py:100`），否则走 `while y + tile <= h` 那条，`rows` 为空，
到 `sliding_window.py:112` 的 `rows[-1]` 就下标越界。

复现（本批有 **15 张** `clean` 命中，多为 1280×4xx 的窄窗口截图）：

```python
from app.logic_layer.sliding_window import SlidingWindowEngine
SlidingWindowEngine().plan(491, 1280)     # IndexError: list index out of range
```

影响面：`engine.py:248–252` 会把它包装成 `MoireEngineError("capture", ...)`，所以更可能是**该帧失败返回、常驻循环不死**；
但这只是读码推断，**该路径对外的 HTTP 状态码与日志表现本轮未实跑验证**。
一张普通窗口截图就能触发，对无人值守设备属必修项；修法与回归测试待用户定口径。

## 标定建议（`[建议]`，未执行）

1. 先消除分辨率共线性：把每张图**归一到部署帧几何**（板端相机是固定输出，标定就该用它的那一档），
   或按尺寸分层各自报分布，两者都要避免"混池一个阈值"。
2. 归一只保证**内部可比**，不保证与现场同分布 —— 手机 4K 直出里的摩尔纹空间周期 ≠ IMX415 采到的周期，
   缩放会改变现象本身的尺度特征。所以明天摄像头接入后**必须用实拍帧重标一次**，本批只能作预演。
3. 缺失的 107 张若能补回，先补再标；补不回就按 193 报，并附"批次不完整"限定语。
