## 一、原项目核心能力（一句话对齐）

> **SFRNet 是一个仅 7.80M 参数、最深只下采样到 1/8 分辨率的"轻量双通路 U 型分割网络"，能在 4K 超高清图像上逐像素圈出"哪里有摩尔纹"，在自建真实 UHDMD 数据集上以全场最高的 IoU 0.6190 与 Precision 0.6286 超过 SegNet / DeepLabV3+ / HRNet / BiRefNet。**

再压缩成答辩可用的一句：

> **它是目前公开方法中"最省参数 + 最敢保高频细节 + 最不愿误报"的摩尔纹像素级检测器。**

## 二、技术底座盘点：哪些能直接用、哪些必须补

这是后续所有创意的"公共底盘"。**任何一组创意都不得跳脱这张表**，否则就是脱离原项目。

| # | 技术资产 | 现状（实测/论文） | 可直接迁移的场景类型 | 迁移代价 |
|---|---|---|---|---|
| A1 | **像素级二分类分割输出**（同分辨率掩膜 + 概率图） | 输出 `[1,1,H,W]`，阈值 0.5 二值化 | 一切"圈出某类区域"的任务：伪影、缺陷、纹理破损 | 0（只换标签定义） |
| A2 | **限制下采样至 H/8 + ASPP 补感受野** | 保高频；DB 稠密空洞 RF=19 | 细密条纹、细裂纹、细网点类目标 | 0 |
| A3 | **SAFM 多尺度注意力**（三分支金字塔 + 跨尺度软门控） | 与论文 Eq.(1)~(4) 零误差对齐 | 同一张图中"粗细并存、空间非均匀"的图案 | 0 |
| A4 | **FRM patch 级 MoE 路由**（四象限裂变、δ=16、26.56% 面积冗余） | ⚠ 实测 **Router 已 100% 坍缩到 branch_1**，其余三条为死参数 | 局域纹理自适应 | 中（须先修坍缩，见 §3） |
| A5 | **滑窗推理 + 概率图平均** | tile=512 / stride=256，4K 峰值显存 0.92 GB | 任意分辨率大图、工业面阵相机 | 0（需修 2 个 bug） |
| A6 | **7.7999 M 参数**（全场最低，比 HRNet 少 73%、比 BiRefNet 少 96%） | 实测 | 边缘设备 / 手机端 / 无人机机载 | 0（需做部署工程） |
| A7 | **"宁可漏检不可误报"的价值取向**（Precision 优先） | Precision 0.6286 / Recall 0.9942 | 质检、安防、金融风控等"误报代价高"的场景 | 0（直接是卖点） |
| A8 | **倒金字塔轻头部**（输出头 aspp_out+output 仅 0.36% 参数） | 实测 | 便于改多头（分割 + 回归 + 分类） | 小 |

### 现存短板 → 但**每一个短板都能包装成大创创新点**

这是本方案最重要的判断：**不要回避短板，短板就是你的题目。**

| 短板（实测） | 严肃表述 | 转写成大创创新点的角度 |
|---|---|---|
| Router 坍缩、无负载均衡损失 | MoE 条件计算未真正兑现 | **"面向 IX 场景的双通路路由修复：负载均衡 + 频率感知 Router"**——方法创新，可写论文/软著 |
| FLOPs 372 G、4K 延迟 3.44 s，实时性差 | 论文自陈 Limitations | **"基于实测算力分布的结构化裁剪：砍 d3 一半通道省 21% 算力"**——有依据的压缩，非瞎剪 |
| 解码器占 73% 算力（d3 独占 42.84%） | 参数量与算力严重脱钩 | 同上的裁剪依据 + **多尺度注入 f2 替代单点注入** |
| UHDMD 未开源、数据靠人工拍摄标注 | 论文 Limitations 自陈 | **"物理先验驱动的自动标注"**——自行设计的数据生成装置，摆脱人工标注 |
| 15 项工程缺陷（5 项高危，predict.py 跑不起来） | 不可复现 | **"开源 SFRNet 的工程化复现与基准重建"**——第一周就能出成果，是答辩的"诚实分" |
| 只检测不去纹 | 任务边界 | **"检测→定位→质量分级→工艺反馈"闭环**，把模型变成产品 |
| 指标打印的是 F2 而非 F1 | 可复现性断裂 | 顺手修正，写进"我们做的复现核验工作" |

## 三、横向技术中台（强烈建议先做，成本极低、加成极高）

以下三项不是独立场景，而是**可以让所有场景一起吃到加成**的通用改造，成本低、答辩加分高。

### T1｜修复 Patch-MoE 路由坍缩（方法创新，最高性价比）

**为什么值得做**：本人已在 `SFR_best.pth` 上实测到三份铁证——① 40 张类真实输入、160 个 block **100% 落入 branch_1，且最大后验仅 0.2797**；② branch_0/2/3 梯度**严格为 0.000000**（永久死参数）；③ 加载权重后 MACs 恒定 179.9905 G，动态计算图退化为静态图。这意味着**论文最有分量的创新点在工程上尚未兑现**。

**改造清单**（文档 §9.2 已给出可直接抄的方案）：

1. 加 Switch Transformer 式负载均衡辅助损失 `L_aux = N·Σ f_k·P_k`，`α≈1e-2`；
2. Soft 路由：Top-2 加权，保证每个 block 至少两条路径有梯度；
3. 改 `FRM.py:156` 的 `AdaptiveAvgPool2d(1)` → 拼接 `[均值, 峰值, 方差]` 三个统计量（均值池化恰好抹掉了判别"平坦/密纹/大波"所需的频率信息）；
4. 训练期每 epoch 打印路由直方图 + 平均最大概率。

**答辩话术**：*"我们没有停留在复现，而是向我们复现的对象提出了修正——我们证明了它的条件计算机制在特定条件下会退化，并给出了可验证的修复方案。修复后做 IoU 对比，这是我们的方法贡献。*"

### T2｜从"学术指标"翻译到"行业分级指标"

所有工业/文保场景的老师傅不关心 IoU，他们关心：**这一版能不能出厂 / 要不要重拍 / 算几级品**。

**改造**：在 `predict.py` 的概率图之上加一个约 100 行的后处理 + 评分卡模块：

```
概率图 → sigma(P>0.5) → 连通域分析 → 面积占比 ρ / 条纹对比度 c / 条纹主频 f (FFT) / 分布熵
      → 国标/行标查表 → {合格 / 返工 / 废品} 或 {优 / 良 / 差} → 结构化报表(JSON+CSV) + 可视化热力图
```

**答辩话术**：*"学术界停在 mIoU，产业界需要的是 CPK。我们做的这一步翻译，是论文到产品的最后一公里。"*

### T3｜端侧与国产硬件部署（政策加分）

7.8M 参数是本项目最大的隐藏资产。`PyTorch → ONNX → ORT/ncnn/RKNN/昇腾 CANN`，配合结构化裁剪（**依据实测算力分布砍 `d3`**）。设备定为触觉智能 Purple Pi OH2（**RK3576**，4+64G 整板，官方企业店报价 ¥999；核心板 + IMX415 摄像头 ¥200），华为昇腾开发者套件为备选。

**答辩话术**：*"我们做的是把一篇 GPU 上的论文，搬到一个 1000 块钱、5 瓦功耗的国产板子上。"*

### 方案 A｜"实面签"——远程身份核验中的屏幕翻拍攻击取证

| 项 | 内容 |
|---|---|
| **一句话定位** | 把原论文的**第一应用动机**（Face Anti-Spoofing 翻拍检测）做成可演示的轻量取证模块。 |

**业务背景**
黑产在银行/券商/运营商远程开户、人社待遇资格认证、线上考试监考中，用第二台设备播放或翻拍证件/真人视频绕过活体。而"摄像机拍屏幕"这个动作**在物理上必然引入摩尔纹**——这是不需要用户配合、不需要加装硬件的被动取证通道，与"反诈""网络身份认证""远程开户合规"直接挂钩。

**落地方式**
```
采集帧 → SFRNet 滑窗推理 → 摩尔纹概率图
   → 多帧一致性（连续 N 帧同区域出现）+ 面积占比 ρ + 主频一致性
   → 风险分 → {PASS / 疑似翻拍 / 翻拍} → 不否决交易，而是"升级人工复核 / 追加活体动作"
```
产品形态：一个 REST 微服务 + 一个 PyQt/Gradio 演示端；定位是**现有活体 SDK 的增强子模块**，而非替代品（这一定位很关键，符合原论文"误报代价极高"的价值取向）。

**在原有项目上的新增/改造**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| 数据 | **自产即可，零外部合作**：3 部手机 × 2~3 块屏（笔记本/显示器/平板），按 UHDMD 工艺（固定支架、语音快门、无线鼠标换页）采 1000~2000 张。正样本=翻拍证件/人脸；负样本=真人直拍（必须足够多且难，这是防误报的关键） | 中 |
| 架构 | **不动** | 0 |
| 后处理 | 新增 `decision.py`：多帧投票 + 双阈值（<T1 放行、>T2 拦截、中间地带转人工复核——这是金融风控的标准工作流） | 小 |
| 工程 | 修 `predict.py` 三项致命 bug（小图崩溃/权重路径/画布尺寸） | 小 |
| 提速 | 降输入分辨率到 512 直出，或按需求裁 d3 | 小 |

**创新点**
1. **多帧一致性判据**：单帧摩尔纹可能是偶然（如背景条纹衣物），连续帧在同一空间频点持续出现才是翻拍——把静态检测做成**时序检测**，这是超越原论文的一步；
2. **带风险分诊阈值的决策层**：不输出硬判决，输出"证据强度"，契合金融风控的实际工作流；
3. **无额外硬件的被动防御**。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★☆☆（架构零改动，数据自转自销） |
| 成本 | **≈ 0**（手机和笔记本本来就有）+ 云算力（AutoDL 约 1.5~3 元/小时，微调 20~30 小时够） |
| 周期 | 4 周（2 周数据 + 1 周微调 + 1 周演示） |
| 合作方 | 校信息办/网络中心（门禁/考试场景）、本地银行网点科技部门、网安企业做试点 |
| 大创亮点 | 契合"全民反诈""网络身份认证公共服务"，社会安全属性强，评委天然认同 |

**答辩话术亮点**
> "我们瞄准的不是'更准的活体'，而是'更便宜的证据'。对手用百万参数模型和专用硬件做活体，我们用 7.8M 参数、一张普清帧，就能回答一个确定的问题：这张脸，是不是从另一块屏幕上来的。"
>
> "这个方向最大的工程美德是：它宁可放过，绝不冤枉。因为把合法客户判成骗子，是这个行业最贵的一次误报——我们模型的 Precision 优先设计，正是为此而生。"

**可展示的实物/演示**
- **现场 Live Demo（最有杀伤力）**：笔记本放一段人脸视频 → 举手机对着它拍摄 → 大屏实时显示：画面瞬间变红、右上角跳出"Moiré Score 0.87 → 疑似翻拍"；镜头转向现场真人 → 立刻转绿 "PASS"。
- 一个"判别卡对照墙"：10 组真人 vs 翻拍的判定结果卡，含摩尔纹得分与 ROI 热力图。
- 一台 RK3576 板子（Purple Pi OH2）做"离线版"，强调数据不出域、时延 X ms。

### 方案 B｜"印纹卫"——烟包/包装印刷品的龟纹（摩尔纹）在线质检与分级

| 项 | 内容 |
|---|---|
| **一句话定位** | 把"4K 屏摄摩尔纹检测"平移到"工业产线的半色调网点龟纹定位与国标分级"。 |

**业务背景**
烟标、药包、酒标、纸箱彩面普遍采用半色调网点印刷；当加网角度、加网线数与扫描/拍摄设备采样频率接近时，必然产生"龟纹（moiré / 鬼纹）"。目前绝大多数中小型印厂**依赖老师傅目视比对样张**，无量化标准、无留痕、批次一致性差，客诉集中在"这版颜色/纹路不对"。
**云南是烟草大省**，烟标印刷量与技术要求均为国内顶级，本地印务企业（烟标、药包、食品包装）密集，**找合作方的难度是所有方向里最低的之一**。

**落地方式**
```
产线相机/高拍仪 → 每印张取样 → SFRNet 掩膜 → ρ(龟纹面积占比) + 主频 f + 对比度 c + 区位分布
   → 按企业/行标阈值查表 → {放行 / 返工 / 废品} → 自动生成批次质检报表 + 留存热力图
   → 反向给工艺参数建议（调整加网角度 / 加网线数 / 网点形状）
```

**在原有项目上的新增/改造**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| 数据 | 建自己的 **SMT-YN 印刷龟纹数据集**：手机/工业相机拍 MBTI 真实印品 + 半色调网点（halftone）物理合成增强（加网角度/线数可控 → 合成数据的物理保真度高） | 中 |
| 架构 | **不动**（原网络本就在 4K 真实拍摄样本上训练，本场景同为"相机拍周期性结构"，域差距是所有方向里最小的） | 0 |
| 输出层 | 新增 `grading.py`（≈100 行）：面积/主频/方位角统计 + 阈值查表 + CSV/JSON 报表 | 小 |
| 工程 | 批量推理脚本 + 简单 UI（工位机可运行） | 小 |
| 可选加分 | 接 T1（修 MoE 坍缩）后做"路由修复前 vs 修复后"的工业缺陷消融表 | 中 |

**创新点**
1. **从"有没有"到"几级品"**：把二值掩膜升级为国家/行业标准的量化分级，这是论文到产品的关键跨越；
2. **可归因**：不仅判废，还输出龟纹主频与方位角，反推是哪个加网参数出问题——这是"可解释质检"；
3. **建立国内首个面向包装印刷的场景化龟纹数据基准**（原数据集 UHDMD 未开源，这本身就有学术价值）。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★☆☆（技术侧最省。真正的难点在打通一家印厂拿真实样张） |
| 成本 | 工业相机/高拍仪 1000~3000 元（或先用手机+环形光源+固定支架，<500 元）；算力同上 |
| 周期 | 6~8 周（印厂对接 2 周） |
| 合作方 | 本地烟草配套印刷企业 / 药包印刷厂 / 学校印刷中心 / 省内包装协会 |
| 大创亮点 | **产教融合落地最扎实的一类**：有真实工位、真实样张、真实返工率数据，申报书里最好看的一类数字（"漏检率从 X% 降到 Y%""单位年省 Z 万元"） |

**答辩话术亮点**
> "全中国的印厂都在用肉眼判定一种肉眼其实看不准的东西——摩尔纹。它本质上是频率问题，人眼是天生的低通滤波器，而我们的网络不是。我们把这套 7.8M 参数的模型直接放到了产线上，让老师傅的一句"看着有点花"，变成一个带数字和质量等级的报表。"
>
> "我们能做的还不止是判废。我们知道摩尔纹的频率是多少、朝哪个方向，于是我们能反过来告诉机长：把网角偏 15 度试试。这是一个闭环。"

**可展示的实物/演示**
- **实物对比册**：同一张烟标，正常 vs 龟纹超标的实拍件 + 模型热力图 + 分级卡，做成一本像样的"缺陷图谱"，评委可以上手翻。
- **工位 Demo**：一台高拍仪 + 屏幕，现场放一张印品，3 秒出热力图和等级。
- **数据大屏**：批次统计（良率趋势直方图），模拟产线一天的运行。

### 方案 C｜"文保哨兵"——古籍与丝织文物数字化拍摄的伪影质检与数字资产分级

| 项 | 内容 |
|---|---|
| **一句话定位** | 把 SFRNet 变成博物馆/图书馆数字化流水线的"拍摄质量门禁"。 |

**业务背景**
国家文化数字化战略推进下，古籍、书画、丝织品、少数民族文献的大规模高像素采集成为常态。但**绢本书画、织锦装裱、旧书网点印刷插页**在这些高分辨率设备下必然产生摩尔纹——目前的通行做法仍是"馆员逐张目检 + 人工重拍"，成本高、一致性差，且往往在文物已经归库后才被发现。
**云南的资源禀赋极强**：东巴古籍、傣文贝叶经、彝文文献、少数民族织绣与服饰，都是摩尔纹高发对象，且本地校馆方——**合作成本几乎为零（校内图书馆、档案馆、民族博物馆）**。

**落地方式**
```
采集台拍摄 → 后台异步调用 SFRNet → 伪影概率图
   → ① 即时质量反馈：不合格则页面提示"请调整拍摄角度/加网Point/更换光源"并重拍
   → ② 生成 sidecar 伪影掩膜文件（.json/.png），随数字资产入库，供后续去摩尔纹/去网算法或人工精修定位
   → ③ 全库统计：生成"数字化质量年报"，给馆方一个资产健康度
```
主打 slogan：**"防患于 clicks，而非治愈于 after"** —— 与其事后算法去纹（不可逆且耗时），不如进库前拦一道。

**在原有项目上的新增/改造**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| 数据 | 校内即可采集。注意：本场景输入**不是标准 4K**（大幅书画需拼接采集，单幅词条、册页则尺寸远小于 512）→ **正好必须修 `predict.py:42-43` 的小图崩溃缺陷**，这是天然的整改动机 | 中小 |
| 架构 | 不动；但可把最后一次 restore 改为恢复原尺寸（已有修正方案） | 0 |
| 输出层 | 新增 `quality_report.py`：伪影覆盖率 + 分区最差区块定位 + PDF/JSON 报告导出 | 小 |
| 可选加分 | 加一个"伪影严重度 0~100 分"回归小 head（用概率直方图的统计量即可，无需重训） | 小 |

**创新点**
1. **范式创新：从"事后修复"到"入库前拦截"**——把不可恢复的画质损失变成可重拍的流程个 node；
2. **资产化输出**：伪影掩膜作为元数据随数字资产一并入库，这是以往工作完全没有考虑的交付形态；
3. **地域唯一性**：面向少数民族文献与丝织品（东巴纸、贝叶经、织锦）的专属数据基准，具备不可复制性，是很好的"特色和创新之处"章节内容。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★☆☆（技术侧最省之一） |
| 成本 | 学校现有翻拍设备即可；可与校图书馆共建"示范工作站"，几乎零硬件投入 |
| 周期 | 4~6 周 |
| 合作方 | 校图书馆/档案馆、省市图书馆、民族博物馆、古籍保护中心 |
| 大创亮点 | **社会效益与文化政策锚点最强的一类**，评委吃"国家战略 + 地方特色"这一套；且容易产出软著与横向课题 |

**答辩话术亮点**
> "国家的数字图书馆每年新增数以百万计的页面，但没有人问过一个尴尬的问题：这些数字副本里，有多少带着一个本不该存在的花纹？我们的答案是——给它装一道门。"
>

**可展示的实物/演示**

### 方案 D（备选·谨慎）｜基层便携 DR 影像的周期性伪影自动质控

> **明确标注为"高价值但需前置合规"的备选方案**，不建议作为主方向，建议作为上述任一方向的延展。

**业务背景**：移动 DR/体检车/兽医设备的 X 射线探测器与抗散射滤线栅（周期性铅条）混叠，图像出现细密栅条网状伪影。此现象与摩尔纹**同物理机制**（周期性结构 × 离散采样 → 差频）。

**为什么吸引人**：滤线栅是严格周期性器件 → **可物理建模精确合成数据**，正好解决"缺数据"这一本项目最大痛点；且**只做"影像质量质控"，不做诊断**，规避医疗器械监管红线。

**风险**：医疗数据合规、伦理审查、合作门槛高。**必须由指导教师牵头、以体模与公开数据集（如公开胸片数据集）为主，严禁使用任何未脱敏的患者影像。**

若团队确有兴趣且导师支持，可作为"扩展实验"写在申报书的"预期成果"里，不作为主干技术路线。

### 方案 E｜"MoiréMetro 形变放大镜"——主动摩尔纹计量的低成本光学测量系统 ★强烈推荐作为主创新点

| 项 | 内容 |
|---|---|
| **一句话定位** | **别人在消除摩尔纹，我们在驯化摩尔纹**——把它从"伪影"变成一枚放大千倍的形变传感器。 |

**业务背景**
摩尔纹在计量学中从来不是噪声，而是仪器：在被测物表面制备一层周期光栅，微米级形变会被差频效应放大成肉眼可见的条纹。传统方案依赖散斑干涉、全息、激光等设备，动辄数十万元且对环境极度敏感，高校本科实验室和中小工程单位基本用不起。
这正是**中国制造2025/国产仪器替代**语境下典型的"低成本高精度测量"命题。

**应用场景（可挑一个最易合作的下手）**
1. **土木/力学教学实验教具**（最易落地）：混凝土/橡胶/金属试件压缩、弯曲时的全场形变可视化，替代部分应变片；
2. **结构健康监测**：桥梁裂缝扩展、古建筑木构变形、边坡位移；
3. **新能源制造**：锂电池极片干燥收缩、隔膜张力不均；橡胶密封件压缩回弹；
4. **农业食品**：果实硬度/表皮微形变。

**落地方式**
```
在试件表面贴/印一层已知周期 p 的栅格贴纸（成本 几元/㎡，可丝印可打印）
   → 固定相机 + 固定光源，连续拍摄加载过程
   → SFRNet 分割出"摩尔纹条纹区条带"（此时标签不再是"缺陷"，而是"条纹线体"）
   → 条纹骨架提取 + 亚像素级中心线（OpenCV thinning + 灰度重心法）
   → 相位/周期解算 → 位移场 / 应变场 → 伪彩色云图输出
```

**在原有项目上的新增/改造（关键技术资产都用上了）**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| 任务定义 | 从"检测伪影区域"改为"分割条纹条带 + 回归相位/周期" | 中 |
| 头部改造 | **多头输出**：保持分割 head 不变，另加一个轻量回归 head（反正是倒金字塔轻量头，成本 <0.1M 参数） | 中小 |
| **数据（最大亮点）** | **GT 可由物理公式自动生成，不需要人工标注！** 已知光栅周期 p、相机内外参 → 形变场 u(x,y) 对应的条纹图可用 `I = perceivedalbedo·(1 + cos(2π·(x + u)/p))` 直接合成，加载过程可用有限元仿真生成 u **→ 直接绕开原论文"数据依赖人工拍摄与像素级标注"的 Limitations** | 中 |
| sim-to-real | 合成数据训练 → 真实少量样本微调（域随机化：噪声、光照、透视、打印缺陷） | 中 |
| 后端 | OpenCV 亚像素中心线提取 + 相位解包（成熟算法，有现成轮子） | 中 |

**创新点（本方案群中创新性最强）**
1. **范式反转**：从"摩尔纹作为缺陷"到"摩尔纹作为测量介质"，把一篇去伪影工作改造成一台低成本光学测量仪；
2. **物理驱动的自动标注**：用先验物理模型取代人工像素级标注，正面回应原论文的 Limitations，是可写成论文的贡献；
3. **极低成本**：一套装置 = 光栅贴纸 + 一台普通相机 + 一个 7.8M 参数网络，**成本比传统光学测量低 2~3 个数量级**，这正是大创评委最爱的"颠覆式性价比"叙事；
4. **天然跨学科**：信息 + 土木/力学/材料，**跨学院组队本身就是大创评分项**。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★★★（光路稳定性、几何标定和 sim-to-real 是主要难点，需认真做；但 demo 效果极易出） |
| 成本 | 极低——光栅打印/丝印 <500 元 + 现成相机 + 一套夹持/加载装置（可用现成万能试验机） |
| 周期 | 10~14 周，但**第 3 周就能拿出肉眼可见的演示**（见下） |
| 合作方 | 本校土木/建筑工程/力学实验室（**校内资源，零门槛**）；本地工程检测公司、桥梁管养单位 |
| 大创亮点 | 创新性★★★★★，政策契合★★★★☆，实物感★★★★★。**是"从 0 到 1"型选题，最适合冲省/国家级立项** |

**答辩话术亮点**
> "过去所有的摩尔纹研究都在问同一个问题：怎么把它去掉。我们问了一个相反的问题：如果我们故意把它做出来呢？"
>
> "一片几块钱的栅格贴纸，加上一个不到 800 万参数的神经网络，我们做出了一个把微米级形变放大成肉眼可见彩虹条纹的放大镜。它替代的是几十万一台的干涉仪。"
>
> "而且我们必须坦白：这个 Idea 的诞生方式，是我们把原论文的一个 Limitations——'数据依赖人工标注'——反过来当成了突破口。因为我们自己造现象，所以我们知道标准答案。"

**可展示的实物/演示（全场最佳）**
- **Live 触感演示**：一块贴了光栅贴膜的硅胶片，评委**用手指按压**，大屏实时显示对应的形变云图（红=压缩、蓝=拉伸），手指移到哪，颜色跟到哪。**这是可以直接让评委上手的那类 demo，杀伤力最大。**
- **加载实验**：万能试验机上压混凝土试块，屏幕上条纹随载荷增加变密，同时给出一条"载荷—主应变"实时曲线。
- **对照墙**：同一试件，传统单点应变片的读数 vs 我们的全场云图——说明"全场 vs 单点"。

### 方案 F｜"周期消失"——反向检测范式：输配电导线散股 / 防护网破损巡检

| 项 | 内容 |
|---|---|
| **一句话定位** | 把"哪里有摩尔纹"翻转成"哪里**不该有**周期性纹理缺失"——用于电力线路与网面结构的缺陷巡检。 |

**业务背景**
架空输电线由多股铝绞线螺旋绞合，外观呈极稳定的周期性斜向股纹；一旦发生**散股/断股/异物缠绕**，该区域的周期性纹理就被破坏。同理：高速公路隔离栅、边坡防护网、养殖/农业防虫网，**"完好 = 周期性完整"**。
目前主要依赖人工读图或重型大模型，且云南作为水电与西电东送大省、南方电网重镇，线路多位于山区，巡检需求刚性。

**落地方式**
```
无人机长焦拍摄 / 巡检机器人 → 预处理：生成"周期性响应图"
   → 改造成多通道输入送入 SFRNet → 输出"纹理异常区掩膜"
   → 框 + 等级（轻微散股/严重断股/异物） → 推送给运检班组
```

**在原有项目上的新增/改造**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| **输入通道扩展（核心改造）** | 把 RGB 3 通道扩为 `{RGB + FFT 幅度谱对数图 + 局部径向 Radon/自相关周期图}`，改 `sfrnet.py:140` 的 `Stem_Block(3,16)` → `Stem_Block(N,16)`，**其余结构完全不动**（这是本项目倒金字塔结构的巨大优势：改一处即可） | 小 |
| **标签反转** | 标签从"摩尔纹=正样本"改为"**纹理异常=正样本**"（数据驱动即可，无需改代码） | 中 |
| **修复 Router（必做）** | 本场景下"不同区域不同周期"（导线股纹 vs 金具 vs 天空背景）的空间非均匀性极强，正是 patch 级路由本该发挥作用的地方，**必须**接 T1 修复坍缩，否则这个设计辩护不了 | 中 |
| 数据 | 最难的一环：需与电力单位/模拟线路合作；可用公开线路巡检数据集 + 物理合成异常先行验证 | 大 |

**创新点**
1. **检测范式的反向迁移**：从"周期性伪影的出现"到"周期性结构的局部破坏"，这是一个方法论层面的迁移，可写进论文/软著；
2. **显式周期先验注入**：不必指望网络自己学会看频率——用 FFT/Radon 显式提供频率通道，**7.8M 的小模型因此能做大模型的事**；
3. **边缘部署闭环**：7.8M 参数 → 无人机 ROI 机载筛选，只回传可疑帧，**节省传输带宽**，这是运营商最在意的指标。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★★★（难点在数据获取，非算法） |
| 成本 | 无人机可用学校现有的/借用；若无，可用"模拟线路 + 长焦相机"做验证，成本可控在 3000 元内 |
| 周期 | 12~16 周，建议作为项目的**第二阶段**或第二个子课题 |
| 合作方 | 本地供电局/输变电运维单位/科技企业；退一步可用校内高压实验室的模拟线段 |
| 大创亮点 | 产业价值★★★★★（可量化：一次线路故障停电损失数额可观）、示范性强；但与 B / C / E 相比，数据获取与落地门槛更高，建议作为第二阶段 |

**答辩话术亮点**
> "我们做了一次小小的思维反转。原来网络学的是'哪里多了一样东西'，现在我们让它学'哪里少了一样东西'——少的是规律本身。"
>
> "一条导线的价值不在于它有多粗，而在于它有多'规律'。断股发生的时候，是这个规律先坏了。"

**可展示的实物/演示**
- **短视频集 ASMR**：20 段无人机巡检素材的实时处理录像，"正常→绿色 / 散股→红色闪烁 + 蜂鸣"。
- **对照实样**：一段真实的断股导线实物（可从报废线路/示教室获取）放在展台上，**现场举条码扫描式 Our_camera 一照，屏幕立即圈出缺陷**。
- 边缘板子实拍：RK3576 板（Purple Pi OH2）+ IMX415 摄像头，强调"离线、不限网、秒级"。

### 方案 G｜"曦光·边缘"——7.8M 模型的国产硬件端侧部署与结构化裁剪 ★适合做"工程类/创新训练类"加分项

| 项 | 内容 |
|---|---|
| **一句话定位** | 把一篇 GPU 上的 4K 论文，搬到一个千元级、几瓦功耗的国产板子上实时跑起来。 |

**业务背景**
论文自陈 Limitations：4K 延迟 3.44 s、FLOPs 372 G，实时部署受限。而国内大量工业/安防现场无法部署高端 GPU，且**信创与数据不出域**要求日益刚性。这是"低功耗国产边缘 + 轻量模型"的天然结合点。

**落地方式**
```
1) 依据实测算力分布做结构化裁剪：解码器占 73% 算力、d3 独占 42.84%（而仅占 8.21% 参数）
   → 优先砍 d3 通道 / 用深度可分离卷积替换 d3 的 3×3
2) 多尺度注入 f2（替代原 sfrnet.py:181 的单点 H/8 注入）→ 用更少的通道补偿精度
3) PyTorch → ONNX → ORT-int8 / ncnn / RKNN / 昇腾 CANN
4) 精度─时延─功耗三维 Pareto 曲线 + 与 DeepLabV3+ / SegNet 的同平台对比
```

**在原有项目上的新增/改造**

| 改造点 | 内容 | 工作量 |
|---|---|---|
| 裁剪依据 | **直接引用实测算力分布表**（§5.8），不是玄学剪枝，是有据可查 | 0（已有） |
| 架构 | 新增 `sfrnet_lite.py`（d3 通道减半 → 预计省约 21% 总算力） | 中 |
| f2 多尺度注入 | 改 `sfrnet.py` 的融合位置，d1/d2/d3 各注入一次（代价仅 ~27K 参数） | 小 |
| 部署 | ONNX 导出 + INT8 量化校准 + 板端 C++/Python 推理封装 | 中大 |

**创新点**
1. **数据驱动的剪枝决策**：依据真实算力热点分布而非参数量进行裁剪（文档中有一个反直觉发现：`c4` 占 16.09% 参数却只占 1.46% 算力，**按参数量剪枝会剪错地方**）——这是一个很好的技术叙事；
2. **软硬一体 + 国产生态**：能动性契合"国产替代/信创"；
3. **Pareto 前沿评测**：产出一张"精度 vs 时延 vs 功耗"三维对比图，任何大创答辩都需要这样一张图。

**可行性**

| 维度 | 评估 |
|---|---|
| 难度 | ★★☆（工程量大但确定性高，几乎无算法风险） |
| 成本 | Purple Pi OH2（RK3576）4+64G 整板 ¥999/块，核心板 + IMX415 摄像头 ¥200/套（官方企业店实价，已各购 2 件）；昇腾开发者套件可申请；云算力少量 |
| 周期 | 6~8 周 |
| 合作方 | 边缘计算厂商、本地系统集成商；或直接作为任一场景的"部署模块"嵌入 |

## 十、一句话结论

> **这个项目最大的资产不是"能检测摩尔纹"，而是"能以极小的参数代价，在超高清图像上精确感知一类空间周期性异常"——凡是"周期性"存在或缺失的地方，都是它的战场。**
>
> 最推荐的组合是：**以 B（印刷龟纹质检）或 C（文保数字化质检）完成落地闭环、以 E（主动摩尔纹计量）拿到创新性、以 H（路由坍缩修复）体现方法论沉淀、以 G（国产边缘部署）回答"能不能真用"。**
