# datasets/screen_detect — 屏幕检测数据集（Stage-1 YOLO）

本目录用于训练/验证 SDD v2.4.1 §4.2 定义的 Stage-1 屏幕检测模型（`yolo_screen_v1`，YOLOv8n）。
**本目录不入库、不进镜像**（.gitignore 已覆盖），只在开发机本地存在。

## 目录结构

```
datasets/screen_detect/
├── README.md            ← 本文件（标注规范，改动需同步 SDD §4.2）
├── data.yaml            ← ultralytics 数据配置（单类 screen）
├── images/
│   ├── train/           ← 训练图（jpg/png）
│   └── val/             ← 验证图
└── labels/
    ├── train/           ← YOLO txt（与 images 同名，.txt 后缀）
    └── val/
```

## 标注规范（SDD v2.4.1 审核决议，不得擅自放宽）

### 类别口径（唯一正类：`screen`）

| 对象 | 是否标注 |
|---|---|
| 点亮的显示器 / 笔记本屏 / 平板 / 手机屏 / 电视 / 广告机面板 | ✅ 标注 |
| **通电发光的显示面板**（规范表述） | ✅ 标注 |
| 电子墨水屏（不通电发光） | ❌ 不标（整图视为负样本） |
| 关机的屏幕（黑屏、反光的玻璃面板） | ❌ 不标 |
| 桌面 / 墙面 / 键盘 / 无屏杂物 | ❌ 不标（负样本） |

> 口径一句话：**通电发光的显示面板入正类，其余一律不标**。
> 拿不准的按"不标"处理，并记入 `notes.md`（采集记录），宁缺毋滥——错标比漏标的污染更大。

### 框规则

1. 一个框包住**整个显示区域**（含黑边框以内），不含外壳/支架/边框外沿。
2. 多块屏幕各标一框（分屏、多显示器、群聊里的手机屏都算）。
3. 框边缘贴合可见像素，宁可略小 1–2 px，不要把周围墙面框进去。
4. 画面里屏幕占比 < 1% 的远景小屏**也要标**（专治 SDD 风险 #15 远景漏检）。

### 数据构成要求（SDD §4.2 / §8 M-A）

| 项 | 要求 |
|---|---|
| 总量 | ≥ 300 张（首版），采集自 IMX415 实拍场景 |
| 正样本（含屏） | ≥ 150 张，覆盖各距离/角度/亮度/屏幕类型 |
| 负样本（无屏） | 占比 ≥ 30%（纯桌面、墙面、键盘、室内杂物等） |
| 验证集 | 独立拍摄或严格随机划分，与训练集**无同场景连拍泄漏** |
| 补充来源 | 公开数据集 + WiFi 回传通道边演示边采集（审核决议：接受） |

## 训练入口

```bash
# 开发机（需 ultralytics，源码库位于 D:\VIEW\YOLO\ultralytics）
python train/train_yolo_screen.py

# 验收标准（SDD §8 M-A）：val mAP@0.5 ≥ 0.9（单类任务）
# 达不到先查标注口径是否被污染（尤其墨水屏/关机屏混入），不要先调超参
```
